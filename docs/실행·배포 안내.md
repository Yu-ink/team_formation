# 실행·배포 안내 (처음부터 제출까지)

## 0. 준비물
- GitHub 계정, Supabase 프로젝트(6장 실습 프로젝트 재사용), OpenRouter 키, Streamlit Community Cloud 계정

## 1. Supabase DB 주소 복사
1. Supabase 대시보드 → 프로젝트 → 위쪽 **Connect** 단추
2. **Session pooler** 주소를 복사(`postgresql://postgres.xxxx:[YOUR-PASSWORD]@aws-0-…pooler.supabase.com:5432/postgres`)
   - `[YOUR-PASSWORD]`를 DB 비밀번호로 바꾼다. 비밀번호에 `@ # /` 같은 글자가 있으면 DB 비밀번호를 영문·숫자로 다시 정하는 것이 편하다.
   - `db.xxxx.supabase.co` 직접 주소는 Streamlit Cloud에서 연결이 안 될 수 있으니 쓰지 않는다.
3. 테이블은 앱이 처음 시작할 때 `schema.sql`로 저절로 만든다. (원하면 SQL Editor에 `schema.sql` 내용을 붙여 넣어 먼저 실행해도 된다.)

## 2. OpenRouter 모델 고르기
1. https://openrouter.ai/models?q=free 에서 이름이 `:free`로 끝나는 텍스트 모델 3개를 고른다(지금도 있는지 꼭 확인).
2. `OPENROUTER_MODELS`에 1차,2차,3차 순서로 쉼표로 이어 적는다. `openrouter/free`는 쓰지 않는다.

## 3. 깃허브 비공개 저장소에 올리기
1. GitHub → New repository → **Private** → 이름 예: `team-formation`
2. 압축을 푼 폴더의 파일을 모두 올린다(Add file → Upload files). `.github` 폴더가 업로드 화면에서 안 보이면 GitHub Desktop이나 `git`으로 올린다.
3. `.env` 파일은 만들었더라도 **올리지 않는다**(`.gitignore`가 막아 줌).

## 4. Streamlit Community Cloud 배포
1. share.streamlit.io → Workspace settings → Linked accounts → GitHub 옆 **Private access "Connect here"**
2. Create app → 저장소 고르기, Branch `main`, Main file path `streamlit_app.py`
3. Advanced settings → Python 3.12 → **Secrets** 칸에 아래를 자기 값으로(브라우저 자동 완성 값은 지우고 다시 쓴다)
   ```toml
   OPENROUTER_API_KEY = "sk-or-v1-..."
   DATABASE_URL = "postgresql://postgres.xxxx:비밀번호@aws-0-....pooler.supabase.com:5432/postgres"
   ADMIN_PASSWORD = "정한 관리자 비밀번호"
   OPENROUTER_MODELS = "1차모델:free,2차모델:free,3차모델:free"
   ```
4. Deploy → 배포 뒤 Settings → Sharing → "This app is public and searchable" → Save
5. 시크릿 창으로 배포 주소를 열어 로그인 화면이 보이는지 확인

## 5. DB 일시정지 막기(GitHub Actions)
1. 저장소 Settings → Secrets and variables → Actions → New repository secret → 이름 `DATABASE_URL`, 값은 위 주소
2. Actions 탭 → "DB keepalive" → **Run workflow**로 한 번 돌려 초록 체크 확인(로그에 `OK: tf_students …`)

## 6. 연습용 시나리오로 시험(README 5~7항 근거 모으기)
1. `admin` + 관리자 비밀번호로 로그인 → `data/어려움.csv` 고르기, 팀 수 4 → **명단으로 처음 상태 만들기**
2. 다른 창(시크릿 창 여러 개 또는 다른 브라우저)으로 학생 학번 + `1234` 로그인 → 공고 부록 단계를 위에서부터 실행
3. 결과 안내의 첫 단어가 부록 기대 결과와 같은지 확인하고 화면을 캡처해 `img/`에 넣는다
4. 마감 → AI 배정 → 'AI 호출 기록' 표 캡처 → 확정
